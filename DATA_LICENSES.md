# Data licenses and attribution

The root MIT license applies to FlareLedger code and original project documentation. It does not relicense NASA or other third-party content.

## NASA PSI demo data

The included FlareLedger NASA demo JSON records the license of each investigation. The ten selected PSI investigation metadata records explicitly identify CC0-1.0. Keep those license notes, investigation versions, DOI, file IDs, hashes, original units, extraction methods, and quality limitations when importing their numerical data.

- [NASA PSI repository](https://psi.nasa.gov/physci/repo/search?q=combustion)
- [NASA Science Data license policy](https://science.data.nasa.gov/about/license)
- [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)
- [NASA media usage guidance](https://www.nasa.gov/nasa-brand-center/images-and-media/)

Repository metadata for the seed is in [data/demo/seed-reference.json](data/demo/seed-reference.json). The reviewed JSON is included under data/demo/. Verify its checksum before importing it. Future data changes should use a focused data PR.

## Publications and media

A NASA-hosted publication, photo, or video can have its own credits or third-party rights. Check the individual artifact before copying it into the application or presentation. A link in a download catalog is not a blanket redistribution license.

Use original project branding. NASA insignia and logos do not become MIT assets. Keep source credit separate from generated content and do not imply that NASA reviewed the project or its conclusions.

## New assets

For each added dataset, publication extract, font, icon set, image, or design asset, record its title, creator or publisher, source URL, license, and any attribution requirement near the artifact. Keep original license notices and relevant limitations.
