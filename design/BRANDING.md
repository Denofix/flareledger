# Proofonauts branding provenance

Human supplier/design owner: **Timofey (Tymofii1912)**. Denis supplied `proofonauts-logo-pack.zip` and confirmed that the logo was created with neural-network assistance. The generating model was not specified, so no exact tool is invented.

The orbital P, verification mark, Proofonauts wordmark and tagline identify the team. The product remains **FlareLedger**. The interface uses the supplied mark plus the Proofonauts credit, rather than renaming the application.

Served assets are `frontend/public/favicon.svg` and `frontend/public/brand/` variants. The supplied paths are preserved; disclosure text is added, viewBoxes extended and standalone colours reversed for the dark interface. Horizontal marks carry **SI-generated logo**; standalone marks carry **SI**. The UI also provides a readable disclosure beside the logo because embedded icon lettering is small.

No image model was used to modify scientific screenshots or measurements. Lettering arrives as vector paths; no font file is bundled. No NASA insignia, flag or mission identifier is included as branding. Project-supplied assets use the repository's MIT terms; third-party scientific data retain their own terms.

[branding-manifest.json](branding-manifest.json) records source-pack, input and served-file hashes. The unmarked source export is not offered as the final public branding variant. See [SI_USAGE.md](../SI_USAGE.md) and [DATA_LICENSES.md](../DATA_LICENSES.md).
