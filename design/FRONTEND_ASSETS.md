# Frontend asset credits

The first Vue interface uses original project artwork under the repository's MIT
code license:

| Asset | Location | Creator and source |
| --- | --- | --- |
| FlareLedger flame mark | frontend/public/favicon.svg | Original FlareLedger project artwork, created with Codex assistance |
| Navigation and interface icons | frontend/src/components/AppIcon.vue | Original simple geometric SVG paths, created for this project |
| Abstract droplet and orbit illustration | frontend/src/style.css, catalogue feature card | Original CSS artwork; decorative, not measured scientific data |

System font stacks use fonts supplied by the visitor's operating system. No font
file, NASA insignia, third-party photograph or external icon package is bundled.
Scientific values and source citations come from the backend's versioned corpus;
their original terms remain separate under [DATA_LICENSES.md](../DATA_LICENSES.md).
