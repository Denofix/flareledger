# Backend API handoff

Entry point: app.main:app, Python 3.12, FastAPI, internal port 8000, prefix /api.
Swagger: /api/docs. OpenAPI: /api/openapi.json. Public text uses English.

| Method and path | Result |
| --- | --- |
| GET /api/health/live | Process status without database or LLM access |
| GET /api/health/ready | Required corpus readiness; 503 before explicit import |
| GET /api/meta | SHA/version, source statistics, generation availability |
| GET /api/investigations | Ten investigation metadata records |
| GET /api/investigations/{id} | Metadata, sources and quality limitations |
| GET /api/records | All 1132 source rows with their distinct record types |
| GET /api/trials | Only the 647 records marked trial_row |
| GET /api/records/{id} | Original row, quantities, sources and evidence |
| GET /api/series | Six series metadata records, without points |
| GET /api/series/{id} | Complete measured series, original points and limitations |
| GET /api/sources | Original source and citation records |
| GET /api/sources/{id} | A source record and attribution |
| GET /api/evidence/{id} | Original extraction and locator information |
| GET /api/raw-tables/{id} | Included original table text and its attribution |
| GET /api/knowledge-cards | Eight authored source-based summaries |
| GET /api/graph-presets | Original graph presets and rendering instructions |
| GET /api/files | Public-file metadata and URLs; no binary fetching |
| GET /api/search?q=PMMA | Lexical keyword matches with source references |
| GET /api/compare?ids=id1,id2 | Two to four compatible series, without transformations |
| POST /api/ask | Optional bounded explanation; otherwise structured refusal/unavailability with lexical evidence |

List routes return {items, total, limit, offset}. Default page size: 20, maximum:
100, offset: zero. records, trials, series and files accept investigation_id;
records also accepts record_type. Unknown investigation filters return 404.

Details return {item, sources, evidence, quality_issues}. The item is the original
corpus object. Original source records retain URLs, DOI and versions. Missing
objects return JSON 404; unavailable data returns 503 with
error.code=corpus_unavailable. Invalid input returns 422. API responses use
Cache-Control: no-store for the first demo.

## Frontend integration

Use VITE_API_BASE_URL=/api and a Vite development proxy to the local backend.
Production Vercel routing must preserve /api when forwarding to
https://api.flareledger.fun/api/...; API matching precedes SPA fallback. Production
ingress and HTTPS are separate infrastructure work, not enabled by this backend.

Suggested first flow: check ready and meta, list investigations, scope records and
series to an investigation, fetch a measured-series detail, show sources and quality
notes, and provide keyword search. Keep data and evidence accessible when Ask is
disabled, rate limited or unavailable. See [AI setup](AI_SETUP.md) before activation.

## Scientific display

The 1132 rows are not all experiments: 647 trial_row, 469 operating_condition_row,
four flow_visualization_record, four source_note, four condition_definition and
four condition_reference records retain their original types.

All 1844 measured points remain unchanged. Use x.name/x.unit and y.name/y.unit,
source time coordinates, source quality notes and graph preset instructions.
The points field contains ordered two-element arrays: points[i][0] is the x
coordinate and points[i][1] is the y coordinate. It is not an array of {x, y}
objects. Retain the original values and point order when rendering.
uncertainty=null means unavailable, not zero. Camera limitations and ambiguous
values must remain visible. No curve or synthetic data is generated by the API.

Comparison rejects different quantity names or units even if both measurements
use millimetres. Droplet diameter and flame diameter are distinct quantities.
Compatible axes do not establish matched conditions. The endpoint retains source
time coordinates and performs no alignment, smoothing, interpolation, causal
inference, extinction inference or safety recommendation.

## Search and Ask

Search is lexical discovery across investigation text, record labels, knowledge
cards and source titles. It is not vector or semantic retrieval. Up to eight
non-stopword tokens must match. Numerical points and raw telemetry are not
searched as narrative claims. Results include type, ID, excerpt and sources.
Each hit is a flat {kind, id, investigation_id, title, excerpt, source_ids,
evidence_ids, sources} object, not a detail wrapper with an item property.
Fetch the linked record or evidence detail for full locators and quality limitations;
the search excerpt alone does not contain those fields.

Ask accepts only {"question":"PMMA"}, one to 1000 characters, and at most 8192 JSON
bytes. Its own bounded keyword ranking uses OR matching and retains the same flat
retrieved-evidence shape. Search's existing AND keyword behavior is unchanged.

By default Ask returns 503, error.code=llm_unavailable, answer=null,
retrieved_evidence, retrieval_method=lexical_keywords, status=unavailable and
live_generation_available=false. Enabled mode requires a backend key, verified
Gemini/Hydrogen configuration, positive persistent limits and explicit migration.
GET meta reports configuration/state availability without calling the provider.

Generated responses are 200/status=generated with answer, citations
({context_id, source_id, quote}), limitations, provider, model, corpus_version,
generated_by=FlareLedger, scientific_review=false and a visible notice. Exact
excerpts are checked against supplied corpus context, not claimed as NASA quotes
or proof of scientific correctness. No measured points are modified or generated.

200/status=insufficient_evidence has answer=null. No-context requests do not call
the model. Local rolling quotas or an active lease return 429/status=rate_limited
with Retry-After and retry_after_seconds. Disabled generation, provider 429,
network errors and invalid output return 503/status=unavailable, answer=null.
Evidence remains in these responses. There are no automatic retries or paid
fallback. Full setup, limits and recovery requirements: [AI setup](AI_SETUP.md).
