# NASA data and resource register

This register describes the frozen source snapshot, not a fresh availability audit. The ten investigation metadata license records identify CC0-1.0; this does not relicense all NASA web articles, media or third-party resources. Keep each source's terms. Root MIT applies to project code/documentation, not every linked resource.

There are 10 investigations, 9 original tables, 1,132 records including non-trials, 6 numerical series with 1,844 points, 46 source records and 13 quality issues. The 647 trial-row records are not a verified count of independent experiments. The 8,369 catalogue entries are external file listings, not embedded measured datasets. No synthetic numerical values are recorded.
