# Public project language

Status: accepted by the project owner on 2026-11-14.

Use English for the public repository, README, project-authored dataset explanations, UI, and international submission material. Ukrainian may be used for internal team guidance distributed separately.

Preserve original scientific source text, identifiers, measurements, units, source-file hashes, and attribution. The English editorial revision uses seed format flareledger.nasa_demo.v2 and localized field names ending in _en. Its original tables, numerical points, evidence, and source records are unchanged.

Apply this policy through ordinary new commits. Existing Git history remains intact.
