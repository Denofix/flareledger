# Frontend

Implementation target: Vue 3, TypeScript, Vite, npm, and a committed package-lock.json. Read [the technical contract](../docs/TECHNICAL_CONTRACT.md).

The first frontend PR must add a working application, package.json, lock file, typecheck/lint/build scripts, local /api proxy, and documented SPA routing. These commands are not implemented in this bootstrap.

Use English for the initial public UI. Unknown scientific values appear as Not reported. Charts show the measured quantity, units, sources, and limitations. Keep API credentials off the frontend.
